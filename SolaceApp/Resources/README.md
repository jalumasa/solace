# Resources

Place your Firebase config file here once you've created a Firebase project:

- `GoogleService-Info.plist` (downloaded from the Firebase console) — this
  file is gitignored and must never be committed.

Add it to the Xcode project via drag-and-drop once the project exists (see
`../../SETUP.md`), making sure "Copy items if needed" is checked and it's
added to the app target.
